# LinktreeAngularCms

## Descrição

LinktreeAngularCms é uma aplicação desenvolvida em Angular para gerenciar e organizar links em uma interface moderna e responsiva, semelhante ao Linktree. O projeto inclui a criação de componentes para a página inicial e de gerenciamento de links, com suporte a rotas dinâmicas e layouts básicos. A estilização da aplicação foi feita com SASS e conta com ferramentas como ESLint e Prettier para manter a qualidade do código.

Entre as funcionalidades implementadas, destaca-se a lógica de busca de links, definição de tipos para o gerenciamento de dados, e melhorias na apresentação visual do conteúdo. O layout foi otimizado para oferecer uma experiência fluida e intuitiva para os usuários.

## Tecnologias Utilizadas

- **Angular**: Framework principal para desenvolvimento front-end.
- **TypeScript**: Linguagem para tipagem estática e robustez no desenvolvimento.
- **ESLint e Prettier**: Ferramentas para padronização e qualidade do código.
- **Headless CMS**: Abordagem para gerenciamento de conteúdo desacoplado.
